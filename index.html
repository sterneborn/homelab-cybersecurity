Network Architecture

Four networks, separated by trust.

The UniFi Cloud Gateway Ultra routes between dedicated VLANs and applies zone-based firewall policies. The UniFi-managed access point maps wireless clients into the appropriate network without weakening those boundaries.

Trusted

Personal and administrative clients with controlled access to required infrastructure.

Guest

Visitor devices with internet access and isolation from private networks.

Lab/Servers

Proxmox, virtual machines, containers and infrastructure services.

IoT

Smart-home and lower-trust devices with only required integration traffic allowed.

Architecture History

From OpenWrt to UniFi.

The Netgear R7800 and OpenWrt environment was the original routing, firewall, wireless and VPN platform. It established the lab's first segmented design and provided extensive troubleshooting experience. The current UniFi architecture is the next stage of that work, while the OpenWrt documentation remains available as a technical record rather than being presented as the active network.
