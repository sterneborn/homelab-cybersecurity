About

Practical learning with real infrastructure.

I am transitioning into networking and cybersecurity by building a hands-on homelab environment. The goal is to develop practical skills that translate into professional IT environments: network design, troubleshooting, documentation, Linux administration, remote access and security monitoring.

Featured Project

Cybersecurity Homelab

A segmented home network built with OpenWrt, VLANs, WireGuard VPN and Cloudflare DDNS. The project is documented publicly to show both implementation and learning progression.

OpenWrt Router

Configured a Netgear R7800 with OpenWrt as the core router and firewall platform.

Demonstrates
Router configuration, firewall zones, network services and infrastructure ownership.

VLAN Segmentation

Designed separate networks for trusted devices, guests, lab systems and rescue access.

Demonstrates
Network segmentation, isolation, IP planning and security-focused design.

WireGuard VPN

Implemented secure remote access using a dedicated VPN subnet.

Demonstrates
VPN deployment, routing, remote access and secure connectivity.

Cloudflare DDNS

Configured dynamic DNS for a stable VPN endpoint using a custom domain.

Demonstrates
DNS, custom domains, Cloudflare configuration and operational reliability.

Network Topology

Segmented homelab architecture.

The network is separated into dedicated VLANs for trusted devices, guest access, lab systems and rescue access. Remote connectivity is handled through WireGuard.
