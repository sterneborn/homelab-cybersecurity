Featured Project

Cybersecurity Homelab

A segmented home network built with OpenWrt, VLANs, WireGuard VPN and Cloudflare DDNS. The project is documented publicly to show both technical implementation and learning progression.

01

OpenWrt Router

Configured OpenWrt on a Netgear R7800 as the core router and firewall platform.

  • Router configuration
  • Firewall zones
  • Network services
02

VLAN Segmentation

Designed separate networks for trusted devices, guests, lab systems and rescue access.

  • Trusted LAN
  • Guest network
  • Lab isolation
03

WireGuard VPN

Implemented secure remote access using a dedicated VPN subnet.

  • Remote access
  • VPN routing
  • Secure tunneling
04

Cloudflare DDNS

Configured dynamic DNS for a stable VPN endpoint using a custom domain.

  • DNS management
  • Cloudflare
  • Custom domain
