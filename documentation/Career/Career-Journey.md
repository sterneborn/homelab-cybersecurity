# Career Journey

## Direction

I am transitioning from industrial work into IT, with a focus on support, networking, infrastructure, and junior cybersecurity or network operations roles.

The homelab provides a practical environment for learning how clients, networks, servers, and applications interact. The goal is not to present myself as a finished engineer; it is to show a repeatable ability to investigate problems, operate systems, make controlled changes, and document the result.

## Learning Approach

* Hands-on implementation and day-to-day operation
* Documentation-first thinking
* Git and GitHub change workflow
* Structured troubleshooting across technical layers
* Validation of expected and denied behavior
* Reflection on what worked, what failed, and why

## Current Focus

* IT support and structured troubleshooting
* UniFi and network segmentation
* Twingate and WireGuard remote access
* Proxmox and Linux operations
* Docker and self-hosted services
* Monitoring through Prometheus, Grafana, Uptime Kuma, and SmokePing
* Automation through n8n and Knut

## Skills Being Demonstrated

* Translating a problem report into testable hypotheses
* Tracing dependencies from client and DNS through network, host, and application
* Explaining technical decisions in clear language
* Applying segmentation and least-privilege exceptions
* Monitoring services and using evidence during troubleshooting
* Maintaining backup, rollback, and recovery awareness

## Next Focus

* Improve alerting workflows around the current monitoring stack
* Continue the planned Zigbee2MQTT architecture
* Develop Security Onion, Suricata, and centralized log-analysis work
* Keep public evidence current, useful, and privacy-conscious

## Architecture History

OpenWrt was the original network platform and remains an important completed phase of the learning journey. The current network has since migrated to UniFi and expanded to five VLAN segments, including an isolated Twingate Connector network.
