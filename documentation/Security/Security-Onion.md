# Security Onion

## Status

**Planned evaluation — not currently deployed.**

Security Onion is being considered as a future learning environment for network security monitoring, event investigation, and defensive analysis.

---

## Evaluation Goals

* Understand network security monitoring workflows
* Collect and investigate relevant lab traffic
* Practice event triage and evidence-based analysis
* Evaluate resource requirements on the Proxmox platform
* Document safe traffic-mirroring and data-retention choices

---

## Network Considerations

Any future deployment must respect the UniFi segmentation model. Sensor placement, mirrored traffic, management access, storage, and privacy implications will be designed before the platform is introduced.

Security Onion is retained in the roadmap, but this page does not claim an active installation.
